# School Report System

This project is a frontend prototype for a school report portal where students and parents can log in and review online academic reports, attendance, and performance summaries.

## Features

- Student login screen with role selection
- Dashboard with academic summary cards
- Subject performance table
- Teacher comment section
- Full report preview modal
- Download button for print/export
- Responsive layout for desktop and mobile

## Run locally

```bash
cd /home/wtc01/personal_projects/school-report-system
npm start
```

Then open:

```text
http://localhost:3000
```

## Files

- `index.html` – page structure
- `styles.css` – styling and layout
- `script.js` – portal interactions and modal behavior
